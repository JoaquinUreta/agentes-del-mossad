2. Formateo de Texto y Codificación

Este párrafo contiene texto normal para evaluar el espaciado interlineal, márgenes y la correcta visualización de caracteres con acentos y eñes: Cigüeña, camión, lingüística, niño, Ñandú, Éxito.

Prueba de estilos en línea: Texto en negrita (b), Texto fuerte (strong), Texto en cursiva (i), Texto enfatizado (em) y Texto subrayado (u).

Uso de entidades HTML para evitar conflictos de parseo: El símbolo de menor que <, el de mayor que > y el ampersand &.

3. Bloques de Código

Para fragmentos en la misma línea se utiliza la etiqueta dentro del flujo del texto.

Para bloques completos con saltos de línea y espacios preservados se emplea la combinación de <pre> y <code>:

def verificar_renderizado(html):
    # Función de prueba para simular el procesamiento de tokens
    tokens = tokenizar_string(html)
    for t in tokens:
        print(f"Token detectado: {t.tipo} -> {t.valor}")
    return True
